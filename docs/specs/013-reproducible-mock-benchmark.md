# 可复现 Mock 性能实验

状态：实施中。发布证据见 `docs/tasks/thesis/`。

## 目标与范围

用本机可重复运行的 Mock 实验验证 InferLab 的阶梯负载、报告计算和阈值判定。旧实验继续可读。真实 API 仍走原有授权和本地 Runner 流程。本规格不改变支付、公开分享或真实 API 指标。

## 阶段与样本

网页 Mock 的阶段时长只约束发送窗口。到点或达到请求总预算时停止派发，等待在途请求在各自单请求超时内结束，再开始下一档。Run 取消仍立即取消在途请求。保留阶段实际观测时长（包含等待）作为完成吞吐量的分母。P95 使用全部完成样本（含失败），请求超时计入错误率。取消、中断、缺档或样本不足的运行不可用于严格基线对比。新 Mock Run 使用版本 `0.1.1`，真实 API 的本地 Runner 沿用原阶段时限。

## 场景与快照

Mock 目标新增可选 `target.mock_scenario`。空值使用原有演示；`baseline-v1` 固定响应延迟 160 ms，`slow-v1` 固定响应延迟 420 ms，两个版本化场景均不主动返回错误。场景 ID 绑定一套固定行为，变更参数使用新 ID。真实目标拒绝该字段。Run 的不可变配置记录场景、负载、超时及 SLO。不同场景的对照以各自报告为准，严格基线对比要求场景相同。

## 历史复跑与报告

`POST /api/v1/runs/{id}/rerun` 从归属当前身份的终态 Mock Run 读取配置快照并启动新 Run，成功返回 202。复用原启动权限、额度、并发限制和错误契约；历史记录不修改。真实 Run 须重新走授权流程，非终态不可复跑。界面展示场景、配置并发上限、RPS 上限、单请求超时、预算、阶段时长、实测完成速率和样本数。

## 验收与回滚

本机选择两种场景各跑三次，保存快照、构建标识、环境与逐请求样本。按 nearest-rank 复算各档及总体 P95、错误率，并核对阶段阈值。配套测试覆盖阶段边界、取消、场景输入和复跑隔离。本变更无需数据库迁移。回滚到上一构建时保留数据库备份，核对降级版本不支持的固定场景，详情见交付运行手册。公共环境验收按现有 staging 运行手册，无法验证的配置单独记录。
