# 项目章程

状态：`accepted`

## 目标

建设一个可在线运营的 AI 推理服务上线体检平台，让开发者在受控预算内完成 Mock 或已授权 API 的阶梯实验，并得到可复核的性能报告、SLO 判断和下一步行动建议。

## 首个可运营版本

- 账户和实验归属。
- Mock OpenAI-compatible 服务。
- 本地 Runner 和受控真实 API 测试。
- 并发阶梯、RPS、请求数、时长、超时和取消。
- SQLite 起步，支持后续迁移关系数据库。
- 基础报告、历史记录和可比较实验。
- 支付订单、服务端核验和权益记录。
- staging、production、监控、备份和回滚流程。

## 非目标

第一阶段不做 Kubernetes Operator、分布式压测、自研推理引擎、GPU 调度、多地域执行和无法审计的任意 URL 压测代理。

## 成功标准

用户能从创建 Mock 实验开始，获得由真实采样计算的报告；刷新或重启后 Run 状态仍可恢复；错误、取消和预算限制可解释；真实 API、支付和示例数据始终明确区分。
