# 安全和线上运维

状态：`accepted`

## 目标访问安全

- 默认只放行 Mock；真实目标必须有授权声明和明确的使用预算。
- URL 解析、DNS 解析后的连接地址、端口和重定向都要重新校验。
- 拒绝回环、私有网段、链接本地地址、云元数据地址和危险协议。
- 运行器使用 context 超时和取消，达到并发、RPS、总请求数、总时长或费用预算立即停止。
- OpenAI-compatible 请求只允许 HTTPS endpoint；解析后的所有地址拒绝回环、私有、
  链接本地、未指定、多播和云元数据地址。重定向不跟随，每次连接重新执行解析校验。
- API Key 可来自 Runner 环境变量，或网页发起的同源临时交接；后者仅在 API 内存
  暂存5分钟，绑定单个 Run 并一次领取（见 spec 009）。任务文件、数据库、错误和
  日志不含 Key。任务令牌也是短期取密凭据，必须按敏感文件保护。
  HTTP 401/403、4xx、5xx、超时、取消、连接失败和响应格式错误使用
  不含敏感内容的分类错误码。

## 身份、数据和日志

- 用户只能读取自己的实验、Run、报告和订单。
- 密钥从环境变量或阿里云密钥管理服务读取，禁止写入仓库、数据库和镜像层。
- 日志记录 Run ID、阶段、计数、错误类型和耗时，不记录 Prompt、Token、响应正文和授权头。
- 共享报告默认脱敏；删除和导出操作需要审计记录。

## 支付

支付宝/VibePay 实现 `PaymentProvider` 接口。权益只能由服务端验签、查单、校验商户订单号/金额/币种并幂等处理后授予。支付跳转页不能直接修改权益状态。退款必须可撤销或调整权益。

## 阿里云发布

- local、staging、production 使用独立配置和数据库。
- 服务器部署必须有 HTTPS、反向代理、健康检查、日志轮转、资源上限和最小权限账号。
- 发布前创建数据库备份或快照；发布后检查 `/healthz`、登录、创建 Mock 实验、运行、报告和支付回调状态。
- 失败发布优先回滚应用版本；数据库迁移必须向后兼容或有逆向方案。
- 删除实例、数据库、DNS、备份等不可逆操作需要人工确认。
