# 外部依赖

- 收费：Owner 确认价格后另行授权查找或准备商品。私有只读查询如获授权，需要从 https://pay.watcha.cn/console/account 安全提供 Agent 凭证。
- 沙箱：Owner 在对应商品控制台配置档位，通过同一测试账户的购买链接模拟购买；将沙箱 runtime Key 和权益 ID 安全注入 staging，再复查同账号为 granted。Fake provider 仅提供本地契约证据。
- 正式：独立 live Key/权益、运营域名、支付宝签约审核和商品上架、收款限制核实、获授权的非收款方买家验证、退款与权益处置流程均待办。签约审核完成以渠道状态为准；未知限额标为未核实。
- 监控：独立探测运行位置、通知接收方和密钥待设置。公网域名、TLS、主体与备案、支持入口和条款/隐私/保存期均待 Owner 确认。
- 当前批次仅交付本地证据与 draft PR。没有 staging/production 发布、真实交易或公开注册变更。
