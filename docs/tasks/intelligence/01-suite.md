# 评分套件 canary-v1

状态：评分核心已实现，集成与 staging 验收由主任务记录。

- 文件：`services/api/intelligence_suite.go`、`services/api/intelligence_suite_test.go`。
- 固定五维各两题：reasoning（逻辑推理）、math（数学计算）、instruction（指令遵循）、structured（结构化输出）、context（上下文检索）；题号采用 `<维度>-1`、`<维度>-2`。
- 题目是项目自编的公开合成数据；不引用外部基准成绩，不推断人类 IQ、供应商身份或通用智能。修改题目、答案或评分规则必须使用新套件版本，避免历史分数混用。

## 评分规则

每题重复 1–3 次；轮次从 1 开始。非 JSON 题去掉首尾空白后，必须整个输出精确等于公开答案，解释、单位、代码围栏或仅包含正确答案都不能通过。

结构化题必须为单个 JSON 对象。字段顺序和 JSON 空白不限；字符串允许合法转义。字段名、集合、值类型、值及数组顺序必须匹配，拒绝未知字段、大小写变种、缺字段、重复键（包含转义后的同名键）、尾随 JSON 或文本。数字答案要求整数文本 `3`，不接受 `"3"`、`3.0` 或指数形式。解析过程同时拒绝嵌套对象重复键。

总分和维度分均为 `通过数 / 计划题数 × 100`；错误、未完成题均不获分。`completed` 包括已返回传输错误的题；`error_count` 仅计请求错误，不计回答错误。`complete` 表示所有计划题已返回结果；完整但包含传输错误的结果仍不参与历史基线比较。缺题报告明确标记不可比较。

服务边界负责拒绝未知题号、越界轮次、重复结果、非有限耗时及非白名单错误码；汇总函数额外忽略未计划和重复的题目槽位，避免分母被错误输入放大。输出为结果副本，请求错误强制设为未通过。原始回答只用于进程内评分；报告仅保存题号、轮次、通过状态、耗时及错误码，不含回答或 Prompt。

Mock fixture：reference 精确回答全部题目（100 分）；degraded 仅精确回答 math/context（40 分）。两者均在本地实际经过相同评分函数，不访问外部服务，不能当成真实模型检测结果。
