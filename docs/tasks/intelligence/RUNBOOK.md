# 智力检测操作与回滚

## 体验

在已启动的 InferLab 侧栏打开“智力检测”，点击“新建检测”。选择 Mock、reference 场景和每题重复次数，启动后逐项记录结果。页面可刷新恢复进度；终态可“同快照复测”。degraded 场景故意给出部分错误回答，用于观察40分和分维变化。

“智商雷达”按模型、目标、题库、重复次数与评分版本归组。第一次检测后能查看五维得分；当前检测之外至少三次成功、完整且无传输错误的记录构成均值基线。正常规则下降15分触发“值得复核”。Mock场景变化在详情和历史中披露。

真实测试在创建表单选择“真实 API”，填写已获授权的 HTTPS 地址、模型和授权选项，然后下载 task.json。按页面命令在本机运行。任务令牌只保存在页面内存，刷新后需使用已下载文件或取消记录后重新授权创建。详细限制及密钥交接见 [本地 Runner](04-local-runner.md)。

## 本地启动和验证

根目录运行 `make api-run`，另一终端运行 `cd apps/web && npm run dev`。
容器构建沿用 `docker build -f infra/Dockerfile -t inferlab:intelligence-preview .`。

```bash
python3 -B scripts/intelligence_smoke.py --output /tmp/inferlab-intelligence-browser
```

需要前端已构建、Python Playwright 与 Chromium。脚本使用临时数据库及本机进程，覆盖三条参考基线、网页创建部分错误场景、刷新、雷达、复测取消、归属隔离与390px布局，截图保存到新目录。测试数据来自Mock。后端fake TLS测试用于真实协议验收。

## 部署与回滚

无需新环境变量或SQLite架构迁移。记录构建ID并用SQLite backup保存发布前副本。staging沿用既有独立数据库、HTTPS、会话密钥与管理员初始化配置。发布后验证登录门禁、检测页、一次Mock报告、复测和雷达，真实外部请求由授权用户另行触发。

回滚时先停止新构建、保留当前数据库副本，再恢复匹配的旧前后端构建。旧构建缺少能力配置识别，应在独立演练库验证，或依部署手册确认后恢复发布前备份；保留新库以备恢复能力报告。新版本启动按既有规则将未完成任务标为中断，不自动重复执行目标请求。

## 已知范围

题库是公开合成探针，可观察其范围内的任务表现。真实结果来自本地客户端上报。雷达只读取本人最近100条能力记录。取消真实任务的网页记录不会停止本机进程，停止请求请用Ctrl+C。
