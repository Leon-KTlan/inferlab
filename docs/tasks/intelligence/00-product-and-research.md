# 产品方案与公开测评参考

## 已核查来源

2026-11-22 只读查看用户提供的 Chrome 灵算页面。检测页以小时分组展示生成任务的完成时间、状态和卡片，雷达页展示题目分项、总分、档位、耗时、成本及来源说明。其页面声明分数来自 codexradar 公开测评，价格按官方 API 标准价折算。InferLab 自己的检测使用自身采样与固定规则。

- [灵算智力检测](https://lingsuan.si/intelligence-test)和[智商雷达](https://lingsuan.si/iq-radar)。借鉴时间线、来源标识、逐项详情和观察历史的交互。
- [Simon Willison 的鹈鹕骑自行车系列](https://simonwillison.net/tags/pelican-riding-a-bicycle/)。短生成任务便于观察模型输出，但人工评图依赖具体判据。其 [2025-11-13 博文](https://simonwillison.net/2025/Nov/13/training-for-pelicans-riding-bicycles/) 讨论固定题被针对性训练，并建议更换动物和交通工具观察泛化。因此本项目披露固定题库范围、版本和具体评分规则，后续换题提升套件版本。
- [codexradar](https://codexradar.com/)。公开页面提供多任务和模型配置的比较。InferLab 保存自己的配置和重复次数，不搬运第三方得分到用户报告。
- [LiveBench 仓库](https://github.com/LiveBench/LiveBench)及[论文](https://arxiv.org/abs/2406.19314)。仓库明确采用有可验证标准答案的题，自动评分而无需 LLM judge，并通过持续更新题目减少污染。本项目借鉴可验证答案与维度拆解，题目由项目自编。

arXiv 的另一次模型漂移论文页面请求超时，未作为本功能设计证据。

## 落地决策

1. “智力检测”是按用户手动触发的能力抽检，默认十道合成题各两轮。五个维度均提供题目和评分规则。原始回复仅在执行进程内处理，平台保留二元评分、耗时和固定错误码。
2. Mock 的 reference/degraded 是人工定义的回答场景，用于体验和验证100/40分变化。真实检测由本地 Runner 对用户授权端点执行，结果展示为客户端回传。
3. “智商雷达”显示最新报告的五维通过率、对比基线和时间序列。按来源、目标、模型、套件、重复数及评分版本分组。至少3次历史可比运行才产生基线。下降15分触发复测提示，这是一条公开观察规则。
4. 请求错误与错误回答分列。未完成或存在传输错误的运行不进入基线。默认使用小型测试和固定参数，结果覆盖题库内的行为。
5. 面向已有 InferLab 用户，视觉延续米白背景、墨绿导航和紧凑的实验记录。保留现有性能实验入口，新增检测和雷达。

## 实现分工

- 评分核心使用 gpt-6.1-sol / high，责任为题库、严格判定、汇总与单测，产物见 01-suite.md。
- HTTP/Mock/雷达使用 gpt-6-astra / high，责任为持久化生命周期、权限和基线规则，产物见 02-backend.md。
- 网页使用 gpt-6.1-sol / high，责任为两个入口及完整交互，产物见 03-web.md。
- 根代理负责跨模块接线、真实任务 CLI、结果审核、集成和发布证据。CLI 测试及操作文档由评分代理补充，见 04-local-runner.md。

验收在隔离本地/本机staging上执行Mock与fake TLS目标。公网真实模型请求留给用户在目标、模型和授权范围明确后从页面触发。
