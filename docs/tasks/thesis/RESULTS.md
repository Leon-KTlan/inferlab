# 本科毕设 Mock 实验结果

2026-11-21 在本机 arm64 macOS 上实测。API 由干净的 `191b729` 构建，精确提交、二进制哈希、运行时间和环境见 [metadata.json](experiment/metadata.json)。测试使用临时 SQLite，实验之间串行执行。

```bash
python3 scripts/thesis_benchmark.py --output /tmp/inferlab-thesis-results --stage-seconds 15
```

并发上限为 1、4、8；每档发送 15 秒，限制 8 req/s；每次最多 800 个请求，单请求超时 1000 ms。两组都使用 P95 ≤ 250 ms、错误率 ≤ 5% 的阈值。正常组固定 160 ms，变慢组固定 420 ms，两组均无主动错误注入。每组第一次新建实验，其余两次从第一次的 Run 快照复跑。第二轮反转两组的执行顺序。

| 执行顺序 | 轮次 | 场景 | 完成样本 | 总体 P95 | 错误数 | SLO |
| ---: | ---: | --- | ---: | ---: | ---: | --- |
| 1 | 1 | 正常 | 333 | 162.77 ms | 0 | 达标 |
| 2 | 1 | 变慢 | 276 | 422.43 ms | 0 | 超标 |
| 3 | 2 | 变慢复跑 | 276 | 422.85 ms | 0 | 超标 |
| 4 | 2 | 正常复跑 | 332 | 162.40 ms | 0 | 达标 |
| 5 | 3 | 正常复跑 | 333 | 162.66 ms | 0 | 达标 |
| 6 | 3 | 变慢复跑 | 276 | 422.87 ms | 0 | 超标 |

6 次运行的 18 个阶段均有至少 20 个完成样本，逐请求记录共 1826 条。由原始样本复算的总体和分档 P50、P95、错误率以及完成速率均与报告一致。正常组各并发档的完成速率中位数约为 6.17、7.93、7.92 req/s；变慢组约为 2.37、7.79、7.79 req/s。并发由 4 提高到 8 时，两组已接近各自的发送上限，完成速率变化很小。完成速率以含在途收尾的观测时长为分母。

这组数据验证平台能识别已知的延迟变化、按快照复跑并正确统计所测场景。它来自固定延迟 Mock 和同一台机器，关于真实推理服务的吞吐与容量需要另行实测。
